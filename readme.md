# 🎬 Premium Emoji → Video Converter Bot

Telegram-бот на **aiogram 3** — конвертирует premium emoji, кастомные эмодзи и стикеры в MP4-видео с настраиваемым фоном, разрешением, качеством и FPS.

---

## 🚀 Установка и запуск

### 1. Системные зависимости

```bash
# Ubuntu / Debian
sudo apt update && sudo apt install -y ffmpeg

# macOS
brew install ffmpeg
```

### 2. Python-зависимости

```bash
pip install aiogram rlottie-python Pillow
```

| Пакет | Зачем |
|-------|-------|
| `aiogram` | Telegram Bot API (v3) |
| `rlottie-python` | Рендер TGS (Lottie) анимаций в кадры |
| `Pillow` | Генерация градиентных фонов + обработка кадров |
| `ffmpeg` (системный) | Сборка видео из кадров, конвертация WEBM/WEBP |

### 3. Настройка

Открой `bot.py` и заполни **две строки** в начале файла:

```python
BOT_TOKEN = "123456:ABC-DEF..."     # токен от @BotFather
ADMIN_IDS = [123456789]              # твой Telegram ID (узнай через /id)
```

### 4. Запуск

```bash
python bot.py
```

## 📱 Возможности

### Для пользователей

| Действие | Что делать |
|----------|-----------|
| Premium emoji → видео | Отправь сообщение с premium emoji |
| Custom emoji ID → видео | Отправь число (ID эмодзи) |
| Стикер → видео | Отправь любой стикер |

### ⚙️ Настройки (`/settings`)

| Параметр | Шаблоны |
|----------|---------|
| 🎨 **Фон** | ⬛ Чёрный, ⬜ Белый, 🟥🟩🟦🟨🟪🟧🩵🩷 цвета, 🔲 Прозрачный, 🌅🌌🌊 градиенты, ✏️ свой HEX |
| 📐 **Разрешение** | 360², 480², 512², 720², 1080², 1920×1080, ✏️ своё |
| 🎬 **Качество** | 🏆 CRF 10 / 🔥 CRF 18 / 👌 CRF 26 / 📦 CRF 35 |
| 🎞 **FPS** | 🎬 24 / 🎥 30 / 🚀 60 |

### 🔧 Админ-панель (`/admin`)

- 📊 **Статистика** — пользователи, конвертации, аптайм
- 📢 **Рассылка** — отправка сообщения всем пользователям
- 🚫 **Бан / ✅ Разбан** — блокировка по Telegram ID
- 📋 **Бан-лист** — список заблокированных

## 📂 Структура

```
bot.py              ← весь бот в одном файле
bot_database.json   ← автоматически создаётся (БД пользователей)
tmp_converter/      ← временные файлы (автоочистка)
```

## 🔧 Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Приветствие + инструкция |
| `/settings` | Настройки конвертации |
| `/help` | Справка |
| `/id` | Узнать свой Telegram ID |
| `/admin` | Админ-панель (только для ADMIN_IDS) |
| `/cancel` | Отмена текущего действия |
